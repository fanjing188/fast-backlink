# 能力与边界

## 填写当前表单

复用已保存的产品资料，按字段标签、标准属性、来源记忆和配方匹配；支持原生输入、选择项、标签、富文本、上传及常见托管表单结构。WordPress 的 Contact Form 7、Forminator、Fluent Forms、Ninja Forms，以及 Webflow、按钮式和 portal 下拉有本地结构回归。跨 frame、Shadow DOM、受控组件也有合成表单测试。

这些不是对所有外部平台的兼容承诺。控件写入后回读不一致、歧义、禁用项或未知结构会留给人工；搜索框里有文字不等于已选中业务项。

## 卡在验证码时存档

在“表单”页点“存档待验证”，保存实际值和人工修改；在“任务”页按产品/仅剩验证筛选，再点“打开并复原”。存档由本机持久保存，不依赖短期浏览器快照。

素材按稳定ID和内容摘要复原，文件重排不会串图；素材改变、找不到字段、登录过期、新增必填项或未完成多步，仍可能要求人工处理。任一已登记 frame 读取失败会拒绝保存半份档案。只在已确认其他内容就绪时显示“仅剩验证”。

验证码、密码、支付字段与授权同意不保存、不代填。人完成验证并亲自提交。检测到提交只记“结果未知”，不冒称平台收稿，未知结果不自动重放。

## 外链资产与换产品

侧栏、素材库和日志页提供“外链库”入口，可按产品、域名/提交地址、状态和类型筛选，查看历史与配方摘要，新增或更新人工核实的平台信息。平台准入和当前产品的复用资格分开：费用与回链要求明确、适配确认、DR及配方仍有效且没有重复/未知结果，才允许准备填写。过期事实不自动续期。

准备会创建或复用本产品的持久待处理项，实际人工提交只标记结果未知，重载与重开也不能自动重投。取消全部适配产品会撤销当前适配，不删除旧证据。更新地址保留旧入口；缺省或UNKNOWN字段不抹掉已有确认，人工明确清空适配及备注按清空意图处理。

清单JSON仅导出当前筛选的摘要；不是含素材与全部证据的灾备。下面的命令用于完整范围的资产导出。

来源库保留提交入口、结构配方、历史状态、证据和按产品隔离的填写记忆；稀疏导入不会抹掉已有事实。导出包含来源、原始表、交接、资料包、可用素材及受限目录内的引用证据，manifest列出摘要和缺失引用。导出可能含身份资料、访问线索或商业信息，应作为私有备份，不上传公开仓库。

```sh
backlink-kit assets export --output "$HOME/backlink-assets.zip"
backlink-kit assets reuse --site mynewproduct
```

reuse 只给候选排序和需要复核的条件，不复制旧产品文案，不把旧产品可投资格当成新产品已获准，不执行外部提交。平台目录默认空白；本项目不公开附送作者的历史来源清单。

## Agent 调用

`backlink-kit fb` 是本机JSON命令通道，可打开提交页、填写、读回、保存快照和记录人工处理状态。基础扩展不要求安装Hermes；传统浏览器采集与后台填入口可能需要另行配置浏览器桥接。一个服务只应连接一个执行浏览器，避免多个扩展竞争领取命令。

外部动作必须来自用户明确任务；命令超时不表示动作没发生。先读回，不盲目重放。`done` 只记待核实，真正受理、公开和链接有效性另行核验。

## 可选 AI

默认关闭。启用后，本机服务向用户配置的兼容接口发送残余字段元数据与允许的候选键信息，模型只能选择已有资料键，不能替用户编造商业事实。公开安装默认关闭值预览与自动采纳；云端接口仍会收到允许发送的元数据。私人字段、验证码和页面HTML不发送。

## 不提供

- 不绕验证码、登录、风控、收费或平台条款。
- 不自动点击最终提交，不发邮件，不保证平台受理、收录或SEO效果。
- 不把本机服务部署为公网SaaS，不承诺生产级多租户隔离。
- 不宣称Linux浏览器、原生Windows、WSL联动或非Chromium浏览器已验收。
- 不把本地夹具测试称为真实平台实投，不附带真实客户资产。
