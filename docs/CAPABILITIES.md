# 能力与限制

## 表单与素材

选择产品后，扩展按标签、字段属性、素材和来源记忆填写当前表单，并回读结果。支持常见输入、选择项、标签、富文本、文件、frame 与 Shadow DOM。无法确认写入、存在歧义或资料不足时交人处理。

人工修改优先保留。不同产品隔离；文件按素材 ID 和内容摘要核对，内容变化时不套用旧文件。

## 外链库与批量任务

外链库提供六列清单、分页筛选、CSV/TXT 导入和 CSV 导出。提交次数按同一平台上的不同成功产品计数。

单页“打开并填写”不点击最终提交。用户显式启动批量任务后，扩展会对合格平台自动提交：免费或免费加付费加速、有效 DR≥10、允许的类型，并且当前产品没有重复或处理中记录。

批量任务每批 5–20 页，可暂停、继续和停止。成功、待人工、失败和未知结果分别保存；未知提交不自动重放，放弃处理也不会撤销已发生的提交事实。

## 登录与待人工

Google 登录接续需要针对当前平台授权。仅在账号及 OAuth 归属能够核实时自动推进；首次授权、密码、验证码、手机号和额外权限由你完成。

待人工存档保存实际值及人工修改，可从卡住的页面打开复原。登录失效、页面改版、新增必填项或缺文件仍可能需要补操作。验证码、密码、支付信息和授权勾选不保存、不复原。

## 可选 AI

AI 默认关闭。你配置接口后，可测试连通、保存设置，再主动点击“AI 智能填充”。模型只能选择已有资料键，不编造商业事实，不覆盖人工输入。接口提供方会收到允许发送的字段元数据；密钥不回显，连接测试不发送产品资料。

## 浏览器权限

- HTTP/HTTPS 内容脚本识别表单和框架；tabs、scripting 与 sidePanel 支持页面操作、登录窗口和批量任务。
- storage 保存连接、设置和浏览器侧快照；alarms 唤醒任务轮询。
- debugger 只在可信输入和文件上传等操作中按需附着，浏览器可能显示调试提示。
- 本机请求使用带令牌的 127.0.0.1 地址；可选 AI 请求由本机服务发给你配置的接口。

## 使用范围

- 本机单用户工具，不能暴露为公网服务。
- macOS 与 Chromium 浏览器链路已验；Linux 浏览器、原生 Windows、Firefox 和 Safari 未支持或未验。
- 不绕验证、风控、收费或平台条款，不发外联邮件。
- 填写成功、平台收稿、外链公开和搜索收录是不同结果，不承诺排名或收录。
- 公共安装从空产品库、空平台库开始；资产备份包含私有资料，不是可公开分享的源码包。
