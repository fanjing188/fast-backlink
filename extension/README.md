# Fast-Backlink 浏览器扩展

<img src="icons/mark.svg" width="64" height="64" alt="Fast-Backlink标识">

辅助填写外链提交表单、保存待验证档案、复用产品素材和来源经验。验证码、授权确认和最终提交由你完成，不是全自动提交机器人。

## 安装与连接

先按[完整安装说明](../docs/INSTALLATION.md)执行 `sh scripts/install.sh`，再 `backlink-kit doctor`、`backlink-kit start`。加载解压缩扩展的目录为 `~/.local/share/backlink-kit/current/extension`；自定义安装以doctor为准。原始源码目录的extension也可供开发加载，但不是自动同步的个人安装。

在Chrome/Edge扩展管理页手动开启开发者模式并加载目录，打开扩展选项，保存start打印的完整本机地址。地址含令牌，不要公开分享。最低声明Chromium116，需要sidePanel；本轮macOS已验，其他平台范围见安装说明。

## 日常操作

| 操作 | 结果 |
|---|---|
| 选择产品 | 以该产品资料匹配当前提交页，先核对资料包是否完整 |
| 一键填写 / Alt+Shift+F | 扫描并填写能安全匹配的字段 |
| 字段候选 / Alt+F | 选择已有资料，不编造缺失事实 |
| 复原快照 / Alt+R | 复原能匹配的保存值，不覆盖新的人工值 |
| 记住表单 | 保存该产品的非敏感填写记忆 |
| 存档待验证 | 保存实际值和人工修改，供集中处理 |
| 任务 → 打开并复原 | 打开档案页面并恢复可匹配内容，验证码留空 |
| 我已提交 | 只记待核实，不代表平台受理或已收录 |
| AI兜底 | 用户配置并启用后才可用，默认关闭 |

页签包括表单、素材、快照、日志、任务和设置。任务支持按产品及仅剩验证筛选；缺文件、多步未完成或未确认项不能冒称只剩验证码。已登记frame读取不全时不写半份档案。

## 存档保护

长久存档由本机保存，不依赖短期IndexedDB。素材按稳定ID和摘要核对；素材变化留空待确认，不按数组下标误传另一文件。不同产品隔离。检测到提交先持久记“结果未知”，不自动再次复原或冒充成功。

登录失效、动态控件、表单结构变化或新增必填项仍可能要人补操作。下拉搜索词存在不等于已选中业务项，受控字段回滚也不会被标为已填。

## 权限和数据

权限、AI数据流与不提供的能力见[能力边界](../docs/CAPABILITIES.md)、[商店文案及权限说明](../docs/STORE_LISTING.md)和[安全说明](../SECURITY.md)。

扩展仅向带令牌的127.0.0.1服务请求资料；可选AI由本机服务访问用户配置的接口。debugger仅在需要可信输入/文件上传时按需附着；浏览器可能显示调试提示。密码、验证码、支付和授权同意值不记录。

数据默认在安装目录data下，来源、文案和素材不随公开源码分发。用户应私密备份，并检查导出manifest中的缺失引用。

## 更新与卸载

停止服务后执行 `backlink-kit update`，在扩展管理页手动重新加载，再start。回滚同样需要手动重载两端。`backlink-kit uninstall --yes`不自动操作浏览器，扩展须手动移除，资产默认保留。
