# 浏览器扩展

安装和连接步骤见 [快速开始](../README.md#快速开始)。扩展需要 Chrome / Edge 116+；连接地址只保存在自己的浏览器中。

## 常用操作

| 入口 | 用途 |
|---|---|
| 产品选择 | 自动保存默认产品；已有任务保留原绑定 |
| 一键填写 / Alt+Shift+F | 填写当前表单中能安全匹配的字段 |
| 字段候选 / Alt+F | 为当前字段选择已有资料 |
| AI 智能填充 | 使用已配置的模型补齐合格空字段 |
| 复原快照 / Alt+R | 复原保存值，保留新的人工修改 |
| 存档待人工 | 保存当前内容，稍后打开并复原 |
| 外链库 | 管理平台、筛选、导入导出和启动批量任务 |

单页填写由你核对并提交；批量任务会自动提交，启动前检查产品和平台清单。遇到登录、验证、付款或缺资料时转人工，结果未知时不自动重投。

Google 登录接续按当前平台授权；首次授权、密码和验证码仍由你处理。存档不会保存或复原敏感字段及授权勾选，文件变化时需要重新确认。

更新或回滚程序后，手动重新加载扩展，再启动本机服务。更多说明：[能力与限制](../docs/CAPABILITIES.md) · [安全说明](../SECURITY.md) · [CLI](../docs/fast-backlink-cli.md)。
